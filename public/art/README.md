# 首页峡谷主视觉

`arena.webp` 为首页与登录页使用的本地装饰背景，1984×793，127,484 字节。

以用户提供的 2D 王者峡谷地图为结构参考，沿用已确定的李白形象和深蓝游戏插画风格，使用内置 ImageGen 编辑，再以 Sharp 转换为 WebP。原始生成图保留在 Codex 生成目录。

当前构图：

- 人物落在右下角，站于敌方一塔附近、与道路连接的局部城墙上，背景随人物位置重新取景。
- 地图整体放大，地形延伸到画幅之外，不展示整张地图的方形外沿或模型底座。
- 人物、一塔附近道路及通往中路的地形为清晰区域；中路之外的其余地图逐步渐隐至深蓝底色。
- 左侧保留文字负空间；不添加天空、群山、远景城市或悬浮人物平台。
- 图片为游戏主题艺术化插画，不作为精确战术地图。手机和平板沿右侧裁切，保留人物。

用户地图附件：`codex-clipboard-52cca0c2-f868-44c4-8757-0da95eea2dc2.png`。游戏角色与场景元素归其权利人所有。

最终内置 ImageGen 提示词见 [arena-prompt.md](arena-prompt.md)。网站开场和页面动效仍由 SVG、Canvas 与 CSS 实现。
