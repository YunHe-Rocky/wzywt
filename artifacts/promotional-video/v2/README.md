# 王者演武堂 · 预告片方向样片

交付文件：`yanwu-trailer-v2-preview-1080p.mp4`，22 秒，1920×1080，30 fps，中文男声与背景配乐。

这是针对第一版被否定后的风格样片，用于确认新的气质，不能视为完整长版宣传片已经获得认可。

## 定位与表达

网站服务于熟人圈的王者荣耀 5V5 内战组织。核心吸引力不是“有多少页面”，而是让熟悉的队友拥有一场认真交锋的机会。

产品优势包括房间邀请与集结、结合分路偏好的分队、实力差距优化，以及英雄/装备资料辅助备战。分队首先处理偏好，再比较实力；不能宣传成人人保证首选位置、绝对公平或保证胜率。实验性 OCR 不作为本片卖点。

这段样片抓住“平时一起上分，这次做一回对手”的情绪。短片不承担完整功能教学，也未演示需要登录的分队过程或虚构满员房间。

## 镜头与声音

- 0–4.5 秒：峡谷集结宣传意象；“今晚，人齐了。”
- 4.5–7.45 秒：剑部特写；“平时一起上分，”
- 7.45–10.7 秒：红蓝对峙宣传意象；“这次，做一回对手。”
- 10.7–15.65 秒：图片加载完成后的真实英雄图鉴悬停、滚动录像。
- 15.65–22 秒：品牌、主张和网站地址；“王者演武堂。和朋友，好好打一场。”

美术由 imagegen 生成，经过动态雾气、粒子、镜头裁切与剪辑合成；不是游戏实录，也不是角色动作视频。字幕、网址和实际网站录像单独制作。中文为 Yunxi 神经网络合成语音，不冒充真人配音演员。
