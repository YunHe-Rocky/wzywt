## 网站定位与本片主线

王者演武堂是面向朋友圈的王者荣耀5V5内战组织工具。价值在于把熟悉的玩家组织到同一场认真较量中：赛事房间和报名负责集结，分路偏好与确定性分队协助安排，英雄/装备资料辅助备战，比赛档案留存本局结果。

核心情绪：“平时一起上分。今天，做一回对手。” 由夜色集结进入分队、备战、交锋，最后回到朋友之间的尊重与下一次相约。

实际分队先按第一到第五志愿满足人数逐级比较，偏好向量相同时再比较估计实力差距。没有保证首选分路、绝对均衡或胜率的承诺；一房一局，不宣传系列赛、分队后反复重算或未完成OCR。

## 素材说明

- AI宣传美术：使用内置imagegen生成四幅新美术，加上短片中的两幅原始美术；镜头裁切、雾气、粒子、光效与剪辑是后续动画合成。这不是游戏实录或生成的角色连续动作视频。新美术与完整提示词在 `art/`。

## 可复现工程

1. `render-film.mjs`：分三段渲染30fps画面；`--stills`只导出分镜抽检图。
2. `mix-audio.py`：生成中文旁白与配乐母带及字幕时间表。
3. `export-film.py`：合并三段画面，按时间叠加真实网站录像并编码H264/AAC。
4. `verify-film.py`：完整解码、检查时长/色彩/响度/黑帧并提取成片画面。

分镜、字幕、实录剪辑时间表及检验报告都保存在本目录。v1和v2保持不变；此制作没有修改网站应用代码或部署。
