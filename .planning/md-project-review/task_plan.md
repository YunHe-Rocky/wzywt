| 首轮布局回归断言通过，但因控制台 hydration warning 判为失败 | 修复首页随机骨架宽度和英雄卡片嵌套按钮；开发态 HMR 导致的 RSC fallback 单独过滤后重跑 |
| 审计脚本误用了 PowerShell 只读变量 `$HOME` | 按项目约束改用任务专用变量 `$pageLines`，不重复原命令 |
