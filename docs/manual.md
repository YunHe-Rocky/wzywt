# 王者演武堂 — 用户使用手册 V1.0.0

## 这是什么？

王者演武堂是一个**王者荣耀 5v5 内战自动分队工具**。它的核心功能是：房主创建一个赛事房间，10 个选手加入后，系统自动把 10 个人分成红蓝两队，保证双方实力尽可能均衡。

分队算法会综合考虑每个选手的：分路偏好、英雄战力、巅峰赛分数、当前段位和历史最高段位。

## 快速上手（5 分钟）

如果你只是想快速开一把内战，按这个顺序做：

1. **注册账号** → 填写召唤师名称、安全问题、密码
2. **配置战力** → 进入「个人空间」，设置段位、分路偏好、英雄战力
3. **创建或加入房间** → 进入「赛事大厅」，创建赛事或输入邀请码加入
4. **分队** → 满 10 人后，房主点击「分队」，红蓝两队自动生成

下面是对每一步的详细说明。

## 第一章：注册与登录

### 1.1 注册账号

打开网站，点击右上角「登录」按钮，切换到「注册」标签页。你需要填写：

| 字段 | 说明 | 要求 |
|------|------|------|
| 召唤师名称 | 你在系统里的昵称 | 至少 2 个字符 |
| 安全问题 | 找回密码时验证身份 | 推荐选你记得住的 |
| 安全答案 | 你设置的答案 | 务必记住！ |
| 密码 | 登录密码 | 至少 11 位 |
| 确认密码 | 再输一遍 | 必须一致 |

> 安全问题有 8 个预设选项，你也可以选择「自定义问题」自己写一个。安全答案在找回密码和注销账号时都需要用到，请务必记住。

密码框右侧有一个**眼睛图标**，点击可以在明文和密文之间切换，方便你检查输入。

注册成功后会自动登录，跳转到首页。

### 1.2 登录

输入召唤师名称和密码，点击「登录」。

### 1.3 忘记密码

1. 在登录页点击「忘记密码」
2. 输入你的召唤师名称，点击「下一步」
3. 系统会显示你注册时设置的安全问题
4. 输入正确的安全答案
5. 设置新密码（同样至少 11 位）
6. 点击「确认重置」

> 如果你连安全答案也忘了，目前只能联系管理员或重新注册。

### 1.4 退出登录

登录后，点击右上角你的头像，在下拉菜单里点击「退出登录」。

## 第二章：个人空间（关键，必须配置）

登录后，点击顶部导航栏的「我的」（或点右上角头像 → 个人空间），进入个人空间页面。

分队算法完全依赖你在个人空间填写的数据。**数据越准确，分队越公平。**

### 2.1 设置当前段位

页面最上方是一个独立的**段位卡片**，左边有一个段位徽章（盾牌形状，颜色随段位变化）。

从下拉菜单里选择你当前的王者荣耀排位段位：青铜 → 白银 → 黄金 → 铂金 → 钻石 → 星耀 → 王者 → 无双王者 → 荣耀王者。

> 段位是账号级别的，不需要每个分路单独设置。

### 2.2 配置分路偏好与英雄战力

段位下方是**分路配置**卡片，包含五个分路行：

| 分路 | 图标 | 说明 |
|------|------|------|
| 对抗路 | 剑 | 上路/战边 |
| 打野 | 爪 | 野区 |
| 中路 | 法阵 | 中单法师 |
| 发育路 | 箭 | 下路射手 |
| 游走 | 盾 | 辅助/游走 |

每行可以操作：

**调整偏好顺序（↑↓ 按钮）**
用上下箭头把你最擅长的分路排到第 1，最不擅长的排到第 5。分队时系统会优先把你分配到你排名靠前的分路。

**添加英雄战力（+ 英雄 按钮）**
点击「+ 英雄」展开添加面板：
1. 在下拉搜索框里输入英雄名称（支持拼音模糊搜索）
2. 选择英雄
3. 输入该英雄的**战力值**
4. 点击「添加」

每个分路最多添加 3 个英雄。添加后的英雄显示在行内，带战力数值。点击 ✕ 可以删除。

> 英雄战力值是你的王者荣耀游戏内该英雄的战力分数。分队时系统会计算你在该分路所有英雄的平均战力，评估你在这个分路的实力。

**填写巅峰赛历史最高分（巅峰 输入框）**
输入你在该分路的巅峰赛历史最高分数。留空表示未设置。

**设置历史最高段位（下拉框 + 勋章）**
选择你在该分路达到过的历史最高段位。这反映了你的分路成就上限。

### 2.3 保存

所有设置完成后，点击底部的「保存配置」按钮。右上角会弹出绿色提示「已保存」。

### 2.4 修改密码

在账户安全区域，点击「修改密码」→ 回答安全问题 → 输入新密码。

### 2.5 注销账号

在危险区域，点击「注销账号」→ 输入 DELETE 确认 → 回答安全问题 → 账号和所有数据永久删除。

## 第三章：赛事系统

### 3.1 创建赛事

1. 点击顶部导航栏「赛事」，进入赛事大厅
2. 在「创建赛事」卡片中填写：

| 字段 | 说明 |
|------|------|
| 赛事名称 | 给房间起个名字，如"周五内战" |
| 截止时间 | 报名截止时间，点击日历选择 |
| 公开房间 | 勾选后房间会在大厅显示，任何人都可以直接加入 |

3. 点击「创建」，你会自动成为**房主**并加入房间
4. 系统生成一个 6 位邀请码，分享给其他选手

### 3.2 加入赛事（选手）

**方式一：公开房间**
在赛事大厅的「公开房间」列表里，找到目标房间，点击直接加入。

**方式二：邀请码**
在赛事大厅的「加入赛事」卡片里，输入房主分享的 6 位邀请码，点击加入。

### 3.3 权限说明

一个赛事有三种角色：

| 操作 | 房主 | 管理 | 选手 |
|------|:--:|:--:|:--:|
| 加入其他房间 | ✓ | ✓ | ✓ |
| 退出当前房间 | ✓ | ✓ | ✓ |
| 执行分队 | ✓ | ✓（5分钟冷却） | |
| 踢出选手 | ✓ | ✓ | |
| 延长截止时间 | ✓ | ✓（5分钟冷却） | |
| 编辑房间公告 | ✓ | ✓ | |
| 公开/私有切换 | ✓ | ✓ | |
| 任命管理 | ✓ | | |
| 撤销管理 | ✓ | | |
| 处理入队申请 | ✓ | ✓ | |
| 添加临时选手 | ✓ | ✓ | |

> 房主可以任命其他选手为「管理」，管理可以协助分队和踢人。但房主 5 分钟内执行过分队操作时，管理不能重复分队，防止误操作。

### 3.4 管理功能详解

**踢出选手**
在选手列表里点击某个选手旁边的踢出按钮。被踢出的管理会先自动降级为普通选手再移除。

**延长截止时间**
点击「延长截止」，选择新的截止时间。如果房主 5 分钟内延长过，管理需要等冷却时间。

**任命/撤销管理**
在选手列表里点击「任命管理」，该选手变为管理权限。点击「撤销管理」取消权限。

**补位选手**
如果房间不满 10 人，可以添加「临时选手」（虚拟占位），分队时会纳入计算。

### 3.5 执行分队

当赛事里恰好有 10 名选手时，房主或管理点击「分队」按钮。

**分队算法的工作流程：**

1. 系统读取所有 10 人的分路偏好和战力数据
2. 尝试所有可能的分路分配方案（113,400 种），为每种方案打分
3. 每种分路方案下，尝试 32 种红蓝分队方式
4. 选择**综合得分最高**的方案作为最终结果

**评分权重优先级：**
- 偏好满足（×500）：最高优先级，尽量让每个人拿到想玩的分路
- 公平罚分（×200）：强者的主分路被抢时罚更多，保护擅长位置
- 段位覆盖（×50）：确保有段位数据的选手被正确评估
- 段位均衡（×30）：红蓝双方段位和尽量接近
- 战力均衡（×15）：红蓝双方综合战力尽量接近

**分队结果展示：**
- 红蓝两队阵容表，显示每个选手分配到的分路
- 战力差数值：≤200 为「完美平衡」，≤500 为「基本均衡」
- 分队结果会保存，刷新页面不会丢失

> 算法中有一个「实力加权罚分」机制：强者被挤出主分路时惩罚更重，弱者补位的代价更小。因此算法会优先把弱者安排去补位，让强者待在擅长的分路。

## 第四章：英雄图鉴

### 4.1 浏览英雄

点击导航栏「英雄」，进入英雄图鉴页面。

- 按分路筛选：对抗路、打野、中路、发育路、游走
- 搜索：输入英雄名称或拼音首字母模糊搜索
- 网格展示所有英雄及其皮肤

### 4.2 查看详情

点击任意英雄进入详情页：
- 英雄原画和皮肤（左右切换）
- 英雄职业标签
- 技能列表和描述
- 所属分路

### 4.3 数据同步

英雄数据从王者荣耀官方网站自动同步。如果某个英雄的分路标注不准确，管理员可以在管理页手动修正，修正不会被后续同步覆盖。

## 第五章：算法深入解释（选读）

### 5.1 综合战力计算公式

每个选手在分配到的分路上，计算一个「综合战力分数」，满分约 1000 分：

| 组成部分 | 计算方式 | 理论满分 | 数据来源 |
|----------|----------|----------|----------|
| 英雄战力 | 该分路 Top3 英雄战力平均值 ÷ 30 | 400 | 你在该分路添加的英雄 |
| 巅峰赛分 | 巅峰赛历史最高分 ÷ 7 | ~357（2500 封顶） | 你填写的巅峰分 |
| 当前段位 | 段位等级 × 15 | 135（荣耀王者=9） | 当前段位选择 |
| 历史段位 | 历史最高段位 × 10 | 90 | 历史最高段位选择 |

举例：一个王者段位（7）、巅峰 1800、对抗路 Top3 平均战力 9000 的选手，分配到对抗路时综合战力约为 267 + 257 + 105 = 629 分。

### 5.2 为什么有时候强者会被分配到自己不想要的分路？

这是因为系统里可能有多个选手擅长同一个分路，而某些分路又缺人。算法必须把某个人挪去补位。实力加权罚分机制确保这种情况下**最弱的选手被挪走**，强者待在自己擅长的分路。

### 5.3 战力差为什么不会到零？

因为 10 个人的实力不可能完全均等。算法做的就是在所有可能的分队方案中，找到均衡度最高的那个。战力差 ≤ 200 已经是非常好的结果了。

## 常见问题

**Q: 为什么我分队时提示"需要正好 10 人才能分队"？**
A: 分队系统只支持 5v5（共 10 人），多于 10 人的选手会被静默排除。

**Q: 分队后可以重新分队吗？**
A: 可以。如果人员变动或想试试不同的配置，可以再次点击分队。

**Q: 管理为什么点不了分队？**
A: 如果房主 5 分钟内执行过分队，管理需要等冷却时间过了才能操作。

**Q: 忘记安全答案怎么办？**
A: 目前无法找回安全答案。如果忘了，只能重新注册账号。

**Q: 英雄战力怎么填？**
A: 打开王者荣耀游戏 → 英雄 → 点击任意英雄 → 查看「荣耀战力」数值。填写你最常用的几个英雄的战力即可。不需要每个英雄都填。

**Q: 巅峰赛分怎么填？**
A: 王者荣耀 → 排位 → 巅峰赛 → 查看历史最高分。填入你的最高纪录。

**Q: 分路偏好顺序影响多大？**
A: 非常大。偏好满足是算法里权重最高的因子（×500）。如果对抗路是你的第 1 偏好，算法会尽全力把你分配到对抗路。
