# 王者演武堂 — 使用手册 V1.0.0

## 欢迎

王者演武堂是一个王者荣耀 5v5 内战分队工具。创建房间、召集选手、一键分队，系统自动根据段位、分路偏好和英雄战力均衡分配红蓝双方。

## 注册与登录

### 注册

1. 访问注册页，输入**召唤师名称**（至少 2 个字符）
2. 选择一个**安全问题**（8 个预设 + 支持自定义）
3. 填写**安全答案**（用于找回密码和注销身份验证）
4. 设置**密码**（至少 11 位）并确认

> ⚠️ 安全答案请务必记住，找回密码和注销账号都需要用到。

### 登录

输入召唤师名称和密码即可登录。

### 忘记密码

1. 点击登录页"忘记密码"
2. 输入召唤师名称，系统显示你的安全问题
3. 填写安全答案，设置新密码

## 个人空间

登录后进入**个人空间** (`/me`)，配置你的游戏数据：

### 分路偏好与段位

选择你擅长的分路和当前段位。段位是分队平衡的核心权重（×100）。

- 可配置多个分路，按偏好排序
- 段位从青铜到荣耀王者

### 英雄战力

搜索并添加你擅长的英雄，输入战力值。分队时系统尽量让你拿到擅长英雄所在的分路。

### 修改密码

点击"修改密码" → 回答安全问题 → 设置新密码。

### 注销账号

危险区域内点击"注销账号"：
1. 输入 `DELETE` 确认
2. 回答安全问题验证身份
3. 确认后所有数据永久删除，无法恢复

## 赛事大厅

### 创建房间

1. 进入赛事大厅，点击"创建赛事"
2. 填写房间名称、截止时间
3. 可选设为**公开房间**（显示在大厅供人加入）或保持私有
4. 创建后获得 8 位房间码，分享给好友加入

### 加入房间

- **公开房间**：在大厅直接点击加入
- **私有房间**：输入房主分享的房间码加入

## 房间管理

### 房主

| 操作 | 说明 |
|------|------|
| 分队 | 满 10 人后一键自动均衡分队 |
| 踢人 | 移除选手 |
| 延长截止 | 延长报名截止时间 |
| 公开/私有 | 切换房间是否在大厅展示 |
| 任命管理 | 指定其他选手为管理员 |
| 撤销管理 | 取消管理员权限 |
| 补位选手 | 添加虚拟人员填补空缺 |
| 编辑公告 | 修改房间公告 |

### 管理 (原"次房主")

| 操作 | 说明 |
|------|------|
| 分队/踢人 | 同房主 |
| 延长截止 | 房主操作后 5 分钟内不可重复 |
| 辞去管理 | 主动放弃管理权限 |

## 分队结果

分队完成后显示红蓝双方阵容：

- 每个选手显示其分路、段位、擅长英雄
- 统计栏显示双方战力差距和段位分布
- 红方 vs 蓝方，数据一目了然

### 分队算法

1. **段位覆盖**（×100）— 确保各分路段位分布均衡
2. **段位均衡**（×50）— 双方整体段位接近
3. **偏好满足**（×10）— 尽量让选手拿到首选分路
4. **战力均衡**（×1）— 英雄战力总和平衡

## 英雄图鉴

浏览全部王者荣耀英雄，支持：

- 按**分路**筛选（上路/打野/中路/射手/辅助）
- 按**职业**筛选（战士/法师/坦克/刺客/射手/辅助）
- **拼音搜索**快速定位英雄
- 点击英雄查看**详情**：技能、皮肤切换

## 首页

首页展示：

- **系统公告** — 版本更新说明，点击展开详情
- **王者官方公告** — 来自官方实时数据，自动更新
- **公开房间** — 快速加入正在招募的房间

## 常见问题

**Q: 房间不够 10 人怎么办？**
A: 房主可以添加补位选手（虚拟人员），确保满 10 人后分队。

**Q: 分队结果能修改吗？**
A: 分队结果持久化存储，刷新不丢失。重新分队会覆盖之前结果。

**Q: 安全问题忘了怎么办？**
A: 目前请联系管理员处理。后续版本会加入更多恢复方式。

**Q: 官方数据多久更新一次？**
A: 监控系统每 60 秒检查一次，检测到变化后自动同步。英雄和皮肤图片自动下载到本地。
