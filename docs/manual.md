## 完整使用流程

```
注册 → 登录 → 个人空间填数据 → 创建/加入房间 → 分队 → 查看结果
```

### 第一步：注册账号

1. 浏览器打开 `http://ywt.yunhe.ink`
2. 点击右上角「登录」→ 切换到「注册」
3. 填写：召唤师名称 + 安全问题 + 安全答案 + 密码（至少11位）
4. 点击「注册」，自动登录

> 📸 ![image-20260625150514823](C:\Users\28484\AppData\Roaming\Typora\typora-user-images\image-20260625150514823.png)

**⚠️ 安全答案务必记住！** 找回密码和注销账号都需要。

---

### 第二步：配置个人空间（必须！）

分队算法完全依赖这里的数据。**数据越准，分队越公平。**

登录后，点击「我的」（#1 在顶部导航栏右侧头像菜单里，#2 在底部 Dock 最右图标）。

> 📸 ![image-20260625150744891](C:\Users\28484\AppData\Roaming\Typora\typora-user-images\image-20260625150744891.png)

#### 2.1 设置段位

页面顶部「段位信息」区域，从下拉菜单选择你的王者荣耀排位段位：

```
未设置 → 倔强青铜 → 秩序白银 → 荣耀黄金 → 尊贵铂金
→ 永恒钻石 → 至尊星耀 → 最强王者 → 无双王者 → 荣耀王者 → 传奇王者
```

分为「当前段位」和「历史最高段位」两个选项。

> 📸 ![image-20260625150923307](C:\Users\28484\AppData\Roaming\Typora\typora-user-images\image-20260625150923307.png)

#### 2.2 分路优先级排序

5 个分路：对抗路 / 打野 / 中路 / 发育路 / 游走

用 ▲▼ 按钮把你最擅长的排第 1，最不擅长的排第 5。算法会优先分配你的高优先级分路。

> 📸 ![image-20260625150952533](C:\Users\28484\AppData\Roaming\Typora\typora-user-images\image-20260625150952533.png)

#### 2.3 添加英雄战力

1. 点击一个分路标签（如「中路」）
2. 在下拉框搜索英雄（支持拼音模糊搜索）
3. 选择英雄
4. 输入战力值（打开王者荣耀 → 英雄 → 查看「荣耀战力」）
5. 点击「添加」

每个分路最多添加 3 个英雄。

> 📸![image-20260625151038152](C:\Users\28484\AppData\Roaming\Typora\typora-user-images\image-20260625151038152.png)

#### 2.4 分路段位

系统自动计算：前 5 英雄战力总和 ÷ 1000 = 段位

例如中路英雄战力之和为 35000，则显示「中路 35段」。每个分路标签右侧都会显示段数。

> 📸 ![image-20260625151103336](C:\Users\28484\AppData\Roaming\Typora\typora-user-images\image-20260625151103336.png)

#### 2.5 巅峰赛分数 + 保存

填写巅峰赛历史最高分，点击「保存配置」。

#### 创建房间

1. 点击「赛事大厅」
2. 填写赛事名称（如"周五内战"）
3. 选择截止时间
4. 可选择公开房间
5. 点击「创建」

创建后自动成为**房主**，系统生成 6 位邀请码。

### 第五步：分队

房间满 10 人后，房主或管理点击「分队」按钮。

#### 分队算法说明

算法分两个阶段：

**阶段一：分路分配（113,400 种方案）**
为 10 个人分配 5 个分路（每个分路 2 人），评分权重：

| 因子 | 权重 | 说明 |
|------|------|------|
| 偏好满足 | ×350 | 最高优先，确保拿到想玩的分路 |
| 段位覆盖 | ×50 | 有段位数据的选手被正确评估 |
| 段位均衡 | ×30 | 红蓝双方段位和接近 |
| 战力均衡 | ×20 | 红蓝双方战力接近 |

**阶段二：红蓝分队**
每种分路方案尝试 32 种分队方式，选均衡度最高的。

**实力加权罚分**：强者被挤出主分路罚更多，弱者补位代价更小。算法优先让弱者补位。

**战力差**：≤200 完美平衡，≤500 基本均衡。

## 常见问题

**Q: 微信打开显示"已停止访问"？**
A: 微信会拦截未备案的 HTTP 链接。**请复制链接到 Chrome/Safari/Edge 浏览器打开。** 不要用微信/QQ内置浏览器。

**Q: 为什么我分队时提示"需要正好 10 人"？**
A: 分队系统只支持 5v5（共 10 人）。

**Q: 管理为什么点不了分队？**
A: 房主 5 分钟内分过队的话，管理需要等冷却结束。

**Q: 忘记安全答案怎么办？**
A: 目前只能重新注册。

**Q: 英雄战力怎么填？**
A: 王者荣耀 → 英雄 → 点击英雄 → 查看「荣耀战力」数值。

**Q: 分路偏好影响多大？**
A: 非常大。偏好满足是权重最高的因子。把你最擅长的排第 1。
