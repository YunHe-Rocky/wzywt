# 王者演武堂 — 使用手册 V1.0.0

王者演武堂是一个王者荣耀 5v5 内战分队工具。创建房间、召集选手、一键分队，系统自动根据段位、分路偏好、英雄战力和巅峰赛分值均衡分配红蓝双方。

## 一、注册与登录

### 注册

1. 点击右上角「登录」→ 切换到「注册」标签
2. 输入**召唤师名称**（至少 2 字）
3. 选择一个**安全问题**（8 个预设 + 支持自定义）
4. 填写**安全答案**（找回密码和注销时验证身份）
5. 设置**密码**（至少 11 位）并确认
6. 注册成功自动登录

> 密码框右侧有眼睛图标，点击可切换明文/密文显示。

### 忘记密码

1. 登录页点击「忘记密码」
2. 输入召唤师名称
3. 回答安全问题 → 设置新密码

## 二、个人空间

登录后进入**个人空间**，配置以下数据（分队算法依赖这些数据）：

### 当前段位

账号级别的王者荣耀段位，从青铜到荣耀王者共 10 级。段位徽章会随等级变化颜色和样式。

### 分路配置 & 英雄战力

五个分路（对抗路、打野、中路、发育路、游走），每行可设置：

- **分路偏好排序**：用 ↑↓ 按钮调整你擅长分路的优先级
- **英雄战力**：点击「+ 英雄」展开，搜索并添加该分路擅长的英雄（每路最多 3 个），填写战力值
- **巅峰赛分**：该分路巅峰赛历史最高分
- **历史最高段位**：该分路历史达到的最高段位

> 分队时系统会根据你的分路偏好排序优先分配，英雄战力用于评估你在该分路的实力。

### 账户安全

- **修改密码**：需先验证安全问题
- **注销账号**：需输入 DELETE 确认 + 安全问题验证，所有数据永久删除

## 三、赛事

### 创建赛事

1. 进入「赛事大厅」
2. 填写赛事名称、截止时间
3. 可选设为公开（大厅可见）或私有（仅邀请码加入）
4. 创建者自动成为「房主」

### 加入赛事

- **公开赛事**：大厅直接点击加入
- **私有赛事**：输入房主分享的 6 位邀请码

### 房间管理

| 操作 | 房主 | 管理 | 选手 |
|------|:--:|:--:|:--:|
| 加入/退出 | ✓ | ✓ | ✓ |
| 分队/踢人/延长截止 | ✓ | ✓（5分冷却） | |
| 编辑公告/公开切换 | ✓ | ✓ | |
| 任命/撤销管理 | ✓ | | |

### 分队

满 10 人后，房主或管理点击「分队」按钮，系统自动计算最优分配：

1. **分路分配**：按偏好排序为每位选手分配分路
2. **红蓝分队**：在保证分路均衡的前提下，平衡双方综合战力
3. **结果展示**：红蓝两队阵容 + 战力差 + 偏好评分

> 战力差 ≤ 200 为完美平衡，≤ 500 为基本均衡。

## 四、分队算法说明

每位选手在分配到的分路上计算综合战力（满分约 1000）：

| 项目 | 公式 | 说明 |
|------|------|------|
| 英雄战力 | 该分路 Top3 均值 ÷ 30 | 满分 400 |
| 巅峰赛分 | 巅峰分 ÷ 7 | 满分 ~357 |
| 当前段位 | 段位 × 15 | 满分 135 |
| 历史段位 | 历史段位 × 10 | 满分 90 |

算法优先级：偏好满足 > 熟练度匹配 > 段位均衡 > 战力均衡

强者会被优先留在主分路，弱者补位；4/5 偏好会受到罚分保护。

## 五、英雄图鉴

- 浏览全部王者荣耀英雄，按分路筛选
- 点击英雄查看详情、技能描述、皮肤切换
- 数据自动从官方同步，分路可在管理页手动修正

## 六、常见问题

**Q: 分队时显示"需要正好 10 人"？**
A: 当前赛事必须有恰好 10 名非观战选手才能分队。

**Q: 管理为什么不能分队？**
A: 房主 5 分钟内执行过分队操作，管理需等待冷却时间。

**Q: 忘记安全问题答案怎么办？**
A: 安全问题答案不可找回，请联系管理员或重新注册。
