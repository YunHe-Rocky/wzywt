## 两个地址与双主题

王者演武堂提供了两套视觉主题，功能完全相同，纯看个人喜好。

```
电脑端推荐    https://example.com/#1    暗金琉璃风格，导航在顶部
手机端推荐    https://example.com/#2    厚玻璃风格，导航在底部 Dock
```

| | #1 演武 | #2 厚玻璃 |
|---|---|---|
| **风格** | 暗底金边，石板灰基底 + 暖铜金强调，卡片呈暗琉璃质感（顶部微光），圆角 6px | 白底蓝调，浅灰基底 + 系统蓝强调，卡片呈厚毛玻璃质感（blur 28px + 多层阴影），圆角 16px |
| **导航** | 顶部 Header 文字链接，移动端汉堡菜单 | 桌面端顶部 Header + 底部 Dock 图标，移动端底部 Dock |
| **光球** | 鼠标驱赶反向逃逸，移动端陀螺仪倾斜驱赶 + 摇晃打散，贴近变亮变清晰 | 青绿 / 亮蓝 / 紫罗兰三色光球，鼠标驱赶 + 陀螺仪倾斜驱赶 |
| **适用** | 桌面主力 | 移动主力 + 桌面可选 |

> 手机浏览器访问会自动检测 UA 并跳转 `/m` 路由。整个网站内部链接自动保留当前主题 hash（`#1` 或 `#2`），无须手动切换。

## 完整使用流程

```
注册 → 登录 → 个人空间填数据 → 创建 / 加入房间 → 分队 → 查看结果
```

## 第一步：注册账号

1. 浏览器打开 `https://example.com`
2. 点击右上角「登录」→ 切换到「注册」
3. 填写表单：

| 字段 | 说明 |
|------|------|
| 召唤师名称 | 你的王者荣耀昵称，至少 2 个字 |
| 安全问题 | 从 8 个预设问题中选择，或自定义一个问题 |
| 安全答案 | 务必记住！找回密码和注销账号都需要验证 |
| 密码 | 至少 11 位 |
| 确认密码 | 再次输入密码确认 |

4. 点击「注册」，完成后自动登录

---

## 第二步：登录

登录页面采用暗琉璃卡片风格设计。点击「登录」后，卡片会触发**玻璃碎裂动画**：

1. **裂纹阶段**（约 0.3 秒）：卡片浮现白色裂纹纹理，模拟玻璃炸裂效果
2. **碎片阶段**（约 2.2 秒）：卡片碎裂为 10x6 共 60 片三角碎片，从爆破中心向外飞散坠落，每片独立旋转 + 位移
3. **过渡完成**：碎片消失，自动跳转到目标页面

普通用户和 `admin` 登录后都进入首页；`admin` 可从 Header 头像菜单的「后台管理」入口进入后台。

登录页面底部有「忘记密码？」链接，点击后可进行三步找回流程：
- **第一步**：输入用户名查询安全提示问题
- **第二步**：输入安全答案验证身份
- **第三步**：设置新密码（至少 11 位）

## 第三步：个人空间（/me）

登录后点击右上角头像菜单中的「修改密码」，或通过导航进入「我的」页面。个人空间是分队系统的数据基础，**数据越准，分队越公平**。

### 头像上传

页面顶部居中展示头像区域。点击头像或「更换头像」文字即可上传：
- 手机相册图片会自动缩放并转换为小于 2MB 的 JPEG，无需手动压缩
- 浏览器无法解码 HEIC/HEIF 时，会提示先在相册中导出为 JPG 或 PNG
- 上传后即时生效，Header 导航栏同步更新
- 可重复更换；重新选择同一文件也会正常提交
- 加载失败时自动回退显示用户首字母

### 游戏身份

填写游戏昵称和游戏 ID 后保存。两项均可留空；赛事房主和次房主可在选手列表中查看所有成员（包括自己）的站内账号、UID、游戏昵称和游戏 ID，普通成员不可查看这些扩展资料。

### 段位设置

两个并排卡片：

| 设置项 | 说明 |
|--------|------|
| 当前段位 | 你目前在王者荣耀中的排位段位，共 11 级 |
| 历史最高段位 | 你生涯中达到过的最高段位 |

段位从低到高：**未设置 → 倔强青铜 → 秩序白银 → 荣耀黄金 → 尊贵铂金 → 永恒钻石 → 至尊星耀 → 最强王者 → 无双王者 → 荣耀王者 → 传奇王者**，共 11 级。每级有对应的盾牌徽章图标和颜色。

### 分路优先级排序

5 个分路：**对抗路 / 打野 / 中路 / 发育路 / 游走**。使用每个分路右侧的 ▲▼ 按钮拖拽排序。把你最擅长的排第 1，最不擅长的排第 5。排序时会有 FLIP 动画平滑过渡。

> 算法在分队时会优先将你分配到你排名靠前的分路，**偏好满足是权重最高的因子**，务必认真排序。

每个分路标签右侧会显示已添加英雄数（如 2/3）和分路段位（如 35 段）。

### 英雄战力

点击一个分路标签进入该分路的英雄管理：

1. 在下拉搜索框中搜索英雄（支持拼音模糊搜索，如输入 "lb" 可搜到 "李白"）
2. 选择英雄
3. 输入该英雄的**荣耀战力**数值（打开王者荣耀 → 英雄 → 查看「荣耀战力」）
4. 点击「添加」

每个分路最多添加 **3 个英雄**，满 3 个后显示提示并隐藏搜索框。

候选列表只展示当前分路相关英雄：主分路匹配的英雄排在前面，后台设置为该路附属分路的英雄排在后面，其余英雄不显示。

### 分路段位计算

系统自动计算：**前 5 英雄原始战力总和 / 1000 = 段位**。英雄战力保持精确原值，段位展示固定向下取整为整数，避免虚高。例如总战力 22115 显示「22 段」。

### 巅峰赛分数

巅峰分数直接影响实力计算，用于分队算法的实力加权。系统根据“历史最高段位”自动判断：

- 历史最高达到 **最强王者** 或更高段位：自动解锁输入，巅峰分最低从 **1200** 起
- 历史最高低于最强王者：输入框完全禁用并显示准入提示，保存时巅峰分强制为 0
- 从低段位切换到最强王者时立即填入 1200；降到门槛以下时立即清空并锁定

### 保存配置

修改上述任何数据后，需要点击底部的「保存配置」按钮才会持久化。成功保存后顶部会有 Toast 提示。

### 修改密码

点击 Header 头像菜单中的「修改密码」，弹出安全验证弹窗：
1. 第一步：显示你的安全提示问题，输入答案验证身份
2. 第二步：验证通过后输入新密码（至少 11 位）并确认
3. 支持键盘操作：Esc 关闭，Tab 焦点循环

### 注销账户

点击 Header 头像菜单中的「注销账户」（admin 用户不显示此选项），弹出注销确认弹窗，需要完成两步验证：

1. 输入 `DELETE` 确认删除
2. 输入安全答案验证身份

> 此操作不可撤销，将永久删除你的账号、密码、安全问题、分路偏好、段位、英雄战力、赛事记录及管理权限。

## 第四步：赛事系统

### 创建房间

进入「赛事大厅」，创建区域填写：

| 字段 | 说明 |
|------|------|
| 赛事名称 | 如"周五内战" |
| 截止时间 | 点击打开日历面板选择日期；小时和分钟通过双列滚轮滑动设置，中心选中项带有「已选」标注 |
| 公开/私有 | 开关切换，公开房间会出现在首页和赛事大厅公开列表中 |
| 公告 | 可选，点击「更多」展开 |

点击「创建」后，系统自动生成 **6 位邀请码**，并跳转到房间详情页。创建者自动成为**房主（owner）**。

### 加入房间

两种方式：
- **公开房间**：在首页「公开房间」卡片或赛事大厅「公开赛事」列表中点击直接加入
- **邀请码**：在赛事大厅左侧「快速加入」区域输入房主分享的 6 位码，点击「加入」

### 权限表

| 操作 | 房主 (owner) | 管理 (co_owner) | 选手 |
|------|:--:|:--:|:--:|
| 加入 / 退出房间 | 创建后自动加入 / 取消房间 | Y | Y |
| 执行分队 | Y | Y (房主操作后 5 分钟内不可重复) | |
| 踢出选手 | Y | Y (可降级管理并踢出) | |
| 延长截止时间 | Y | Y | |
| 编辑公告 | Y | Y | |
| 公开 / 私有切换 | Y | Y | |
| 添加补位选手 | Y（自动命名为"补位1/2/3..."） | | |
| 任命 / 撤销管理 | Y | | |
| 辞去管理 | | Y（降级为普通选手） | |

### 房间详情页

进入房间后，页面展示：

- **顶部标题栏**：赛事名称 + 状态徽章（报名中 / 人满待分队 / 已分队 / 已结束）
- **截止时间**：金色高亮显示，过期变红色，房主可点击「延长截止」调出日历面板修改
- **房间号**：6 位邀请码，点击可复制到剪贴板
- **人数统计**：X/10 人参战 + 补位人数 + 观战人数
- **管理面板**（管理可见）：分队按钮、添加补位、公开/私有切换、辞去管理等
- **房间公告**：富文本展示，管理员可点击「编辑」修改
- **选手列表**：显示每个选手的名称、角色（房主 / 管理 / 选手）、类型（正式 / 补位 / 观众），分队后显示所属队伍（红队 / 蓝队）和分配分路
- **操作按钮**：管理员可踢人、任命管理、撤销管理、降级并踢出；非管理员选手可退出
- 最后一名有效成员离开，或房主注销/被后台删除时，房间及其关联数据会自动删除，不会在大厅保留 `0/10` 空房间

### 分队结果页

分队完成后，页面展示：

1. **分队结果**：红蓝两队卡片，每队显示 5 名队员及各自分配的分路
2. **战力差**：大号数字展示两队实力差距
   - 小于等于 200：绿色"完美平衡"
   - 小于等于 500：金色"基本均衡"
   - 大于 500："差距较大"
3. **偏好分**：衡量队员分路偏好满足程度
   - 大于等于 20：绿色"高度契合"
   - 大于等于 10："基本满足"
   - 低于 10："一般"

## 分队算法详解

分队系统专为 **10 人 5v5** 设计，分两个阶段运行。

### 阶段一：分路分配

10 个人分配到 5 个分路（每个分路 2 人），算法枚举所有可能的分配方案（共 113,400 种），按四层权重评分：

| 权重因子 | 权重值 | 说明 |
|----------|--------|------|
| 偏好满足 | **x350** | 最高权重，确保每人拿到自己排位靠前的分路 |
| 段位覆盖 | x50 | 奖励有段位数据的选手被正确评估 |
| 段位均衡 | x30 | 红蓝双方段位之和尽量接近 |
| 战力均衡 | x20 | 红蓝双方战力之和尽量接近 |

### 阶段二：红蓝分队

每种分路分配方案尝试 32 种红蓝分队方式，选出均衡度最高的组合。

### 实力加权罚分

强者被挤出主分路时罚分更多，弱者补位的代价更小。**算法天生优先让弱者补位**，保证核心选手拿到自己最擅长的分路。

### 实例说明

假设 10 人的战力分别为：350, 320, 300, 280, 260, 240, 220, 200, 180, 150。如果战力差显示 150，说明两队综合实力非常接近；如果显示 600，说明可能有人数据不够准或大家实力差异本身就大。

## 手机端（/m 路由）

手机浏览器访问 `https://example.com` 时，中间件自动检测 UA 并将请求 307 跳转到 `/m` 路由。两套主题在手机端各有不同表现：

```
#1 桌面 → https://example.com/#1        #2 桌面 → https://example.com/#2
#1 手机 → 自动跳 /m/#1（汉堡菜单导航）     #2 手机 → 自动跳 /m/#2（Dock 导航）
```

`/m` 路由覆盖所有主路由的同名页面：
- 首页、赛事大厅、赛事详情、英雄图鉴、英雄详情
- 装备图鉴、装备详情、个人空间
- 登录、注册、调试面板
- 后台管理系统全部页面

手机版布局自动适配小屏幕，组件使用响应式设计。光球系统在移动端启用陀螺仪倾斜驱赶 + 摇晃打散，玻璃阴影会随姿态改变方向；普通手指滚动不会改变背景位置。iOS 首次使用时点击页面上的「启用动态光影」完成系统授权。

## 后台管理系统（/admin）

超管（role 为 `admin`）专属，登录后通过 Header 菜单中的「后台管理」入口进入。后台使用独立 layout，无 Header/Dock，左侧有紧凑侧边栏（w-44）导航。

### 仪表盘

4 个卡片展示核心统计：
- **用户总数**（蓝色）
- **赛事总数**（金色）
- **进行中赛事**（绿色）
- **英雄数量**（紫色）

### 用户管理

用户列表，支持搜索。每个用户可执行：
- **封禁 / 解封**：封禁用户将被拒绝登录，已登录 session 自动销毁
- **删除**：永久删除用户及关联数据

> admin 账号受保护：前端隐藏封禁 / 删除按钮，API 层禁止操作。确保超管永远不会被误删。

### 房间管理

查看系统中所有赛事，不分公开/私有，支持删除任意赛事。

### 英雄分路管理

全英雄列表（可搜索过滤），每个英雄显示名称、当前主分路、附属分路和职业类型。管理员可修改主分路并用多选标签维护附属分路；数据分别保存到 `hero_lane_overrides` 与 `hero_secondary_lanes`。**同步爬虫不会覆盖手动修正的分路数据**，非 admin 的修改请求会由 API 拒绝。

### 系统设置

- **爬取地址配置**：可自定义 5 个爬虫 URL（英雄列表页、英雄列表 JSON、英雄详情页基地址、英雄图片基地址、皮肤图片基地址），每个有重置为默认值的按钮
- **手动同步**：点击「同步英雄数据」触发全量爬取
- **进度条**：实时显示当前同步阶段、当前进度 / 总数、状态信息（同时爬取中 / 完成 / 错误），前端每 800ms 轮询一次

## 常见问题

**Q: 微信打开显示"已停止访问"？**

A: 微信会拦截未备案的 HTTP 链接。请复制链接到 Chrome / Safari / Edge 等独立浏览器打开。不要使用微信或 QQ 内置浏览器。

**Q: 为什么提示"分队需要正好 10 人"？**

A: 分队系统专为 10 人 5v5 设计，只有满 10 人才能执行分队。人数不满时可以添加补位选手凑人。

**Q: 补位选手是什么？**

A: 补位选手是房主手动添加的临时账号，用"补位1""补位2"等名称标识。它不计入后台用户列表和用户统计；房间到达截止时间后，cron 会删除该临时账号及其关联资料。

**Q: 管理为什么点不了分队？**

A: 管理在房主上次分队操作后的 5 分钟内无法点击分队，这是冷却机制。

**Q: 忘记安全答案怎么办？**

A: 安全答案目前无法找回，只能重新注册账号。请务必在注册后妥善记录你的安全答案。

**Q: 英雄战力怎么填？**

A: 打开王者荣耀 → 点击下方「英雄」标签 → 选择一个英雄 → 在英雄详情页查看「荣耀战力」显示的数值，填入网站对应英雄的战力输入框。

**Q: 分路偏好影响多大？**

A: 非常大。偏好满足是分队算法中权重最高的因子（权重 x350），远高于段位均衡（x30）和战力均衡（x20）。把你最擅长的分路排第 1，这是公平分队的核心保障。

**Q: 页面为什么有时加载慢？**

A: 英雄和皮肤图片优先读取服务器本地静态文件，首次载入会由浏览器缓存；只有本地图片缺失时才访问腾讯 CDN 回退源。

**Q: 两个主题有什么区别？**

A: 功能完全一样。#1 演武是暗底金边风格，适合桌面端长时间使用；#2 厚玻璃是白底蓝调毛玻璃风格，视觉效果更现代，手机端体验更好。你喜欢哪个就用哪个，随时切换。

**Q: 手机端为什么没有 Dock？**

A: #1 主题的 Dock 仅出现在移动端，#2 主题的 Dock 同时出现在桌面和移动端。如果你在手机 #1 上只看到顶部汉堡菜单，这是设计如此。

**Q: 后台管理中的英雄分路修改会丢失吗？**

A: 不会。手动修改的分路数据存储在 `hero_lane_overrides` 表中，爬虫同步时不会覆盖手动修正。

**Q: 如何邀请朋友加入房间？**

A: 创建房间后，把 6 位邀请码（如 #A3F8K2）分享给朋友。朋友进入赛事大厅，在「快速加入」区域输入邀请码即可加入。公开房间也可以让朋友直接在首页找到并加入。
