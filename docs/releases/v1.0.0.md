## 主要变化

### 产品与视觉

- 重做首页与演武场主题，统一核心页面、导航、动效和状态反馈。
- 完善桌面端与移动端路由和导航一致性。
- 重组赛事大厅，增加流程说明、空状态、重试和分队结果解释。

### 比赛与分队

- 比赛草稿可恢复，新截图会使旧识别结果失效。
- 补齐识别排队、执行、心跳、取消、重试、低置信度和跨图冲突处理。
- 正式提交前增加确认和记录版本冲突保护。
- 分队计算改由带并发、队列与超时限制的 Worker 线程池执行。

### 鉴权、调度与媒体

- 无效 Session 不再先渲染受保护页面，账号删除进入显式停用流程。
- 私有页面 Lease 在读取、续租和释放时核对当前用户，身份变更后清理旧缓存。
- 页面切到后台时暂停续租，恢复可见或 Lease 过期后自动重连。
- 媒体上传增加用户、每日与全局配额及并发预留。

### 发布与运维

- 建立可备份、migration、原子切换、精确健康验证和失败回滚的发布流程。
- 保留失败 release 现场，保护当前版本和上一回滚版本，设置有界的历史保留。
- 支持外部数据库备份目录，增加 MySQL、Redis、PM2、Nginx 和持久媒体诊断。
- 公网入口验收同时覆盖 HTTPS、反向代理、移动端跳转和激活 Release ID。

## 验证范围

- 版本登记一致性。
- 架构边界、TypeScript、核心逻辑与分队 Worker。
- 鉴权、页面资源调度、入口跳转和移动路由。
- 部署、回滚、备份、Redis 与公网入口回归。
