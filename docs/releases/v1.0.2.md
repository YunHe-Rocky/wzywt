## 改动

1. 修复 Next.js middleware 的 10 MiB 请求复制上限截断视频上传。精确排除上传集合路径，API 内仍独立校验身份；真实 300 秒视频成功，301 秒按规则拒绝。
2. 超管可从工作室将完整主题应用到当前会话：节庆、战事、纪念、人物四类风格覆盖首页、导航、卡片、工作区与开屏。支持手动结束；关闭标签页、退出登录或身份变化后不再继续预览。
3. 将战绩入口拆为 137 行、房间入口拆为 265 行的容器与独立模块，保留草稿、OCR、权限和接口契约。选将页签按需加载。
4. 工作区、管理与调试样式按页面加载，首页 CSS 从 164,360 B 降到 107,172 B，房间页首屏 JS 约减少 5%。
5. 制作素材与下载依赖退出当前 Git 树；部署源码 tar 从约 143 MiB 降至 13.4 MiB。删除约 950 MiB 可重建中间文件，保留本地成品。测试改用约 117 KiB 独立样片。旧 Git 历史未重写。
6. 澄清项目支持直连 Next.js 8001，Nginx 上传配置只在实际经过 Nginx 时适用，不将代理配置当作当前上传修复。
