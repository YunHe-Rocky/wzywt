## 系统设置现在怎么使用

日常更新不需要填写五个地址：进入「系统设置」，确认正在使用的来源，点击「同步英雄资料」。任务完成后，通过「查看更新后的英雄资料」进入前台图鉴。

只有官方路径变化时才展开「高级配置 · 调整数据来源」。每项显示用途、廉颇编号 105 的实际地址示例和恢复默认按钮；头像保留 `{id}`，皮肤保留 `{id}`、`{idx}`。地址与占位符由前后端共同检查，不能保存任意外部来源。

修改后可单独「保存配置」，也可直接「保存并同步英雄」。保存失败不会启动同步，单独保存不会立即改写已有英雄资料。页面区分未保存修改和当前生效来源，支持放弃本地修改。图片下载阶段改为读取保存的头像与皮肤路径，修复此前仍使用固定地址的问题。

同步显示排队、运行、完成或失败状态，刷新或重新进入页面可以继续读取进度。轮询不重叠、请求失败有重试入口，长时间排队可进入运行监控查看；不承诺固定完成时间。

## 视频与手机播放

- 接受 MP4、MOV、WebM。新上传的视频在发布前经过实际解码，生成 H.264 Main/AAC、8-bit yuv420p、最高 720p、30 fps 的 MP4，元数据前置，便于边下载边播放。
- 转码失败、超时、最终大小或时长超限时拒绝发布并清理中间文件；输出变大时重新核对原上传预留，不绕过配额。
- 手机端增加明确的点击播放入口，首次播放与重试直接响应用户点击；仅预读视频信息时不显示持续缓冲。
- 连续缓冲 20 秒后显示重新加载和单独播放入口；重复缓冲事件不延长期限，后到的视频信息事件不会清掉失败提示。
- 旧视频继续使用原文件，不会随本次更新自动转码。原始编码仍不兼容的旧片需要重新上传生成兼容版本，或另行备份后处理。
