## 1. 设计方向

**石板灰基底 + 克制暖金点缀** — 低对比度、长时间舒适、现代工具感。

参考：Linear / Notion 暗色模式 + 王者荣耀古铜质感。

---

## 2. 配色体系

```
背景系统:
  --bg-root:   #1a1d24   石板灰页面底
  --bg-nav:    #1e212a   导航栏略深
  --bg-card:   #22262e   卡片背景
  --bg-hover:  #292d36   悬停态
  --bg-input:  #1e212a   输入框背景

文字系统:
  --text:           #e0e3ea   主文字
  --text-secondary: #b0b4be   次要文字
  --text-muted:     #777b88   辅助文字

强调色:
  --gold:       #b89860   暖铜金 (替代亮金)
  --gold-light: #c8b48c   淡金 (小面积点缀)
  --gold-dim:   #8a7040   暗金
  --red:        #cc6666   柔和红
  --blue:       #6898cc   柔和蓝
  --green:      #78b878   柔和绿

边框:
  --border: rgba(255,255,255,0.06)
  --border-light: rgba(255,255,255,0.04)
  --border-gold: rgba(184,152,96,0.15)

圆角: 统一 6px
```

### 配色原则
- 金色仅用于**强调**（标题、激活态、关键按钮），不是大面积使用
- 正文用灰白色系，不要金色文字
- 减少渐变色使用，按钮例外
- 红蓝队色柔和化，避免刺眼

## 3. 全局组件规范

### 3.1 卡片
- 背景 `--bg-card`，1px `--border`，圆角 6px
- 微阴影: `box-shadow: 0 2px 8px rgba(0,0,0,0.2)`
- 可选左侧 3px 强调线 (金色渐变)
- 悬停: 阴影加深，无上移 (太花哨)

### 3.2 导航栏
- 实色背景 `--bg-nav`
- 链接: 激活态底部 2px 金色下划线
- 用户头像: 暖金圆形边框

### 3.3 按钮
- 主按钮: `linear-gradient(180deg, #c8b48c, #b89860, #8a7040)` + 细微阴影
- 次按钮: `background: #2a2d36; border: 1px solid rgba(255,255,255,0.08); color: #b0b4be`
- 危险按钮: `background: rgba(204,102,102,0.15); color: #cc6666; border: 1px solid rgba(204,102,102,0.2)`
- 悬停: 亮度微升，无上移动画

### 3.4 排版
- 页面标题: 24px Bold
- 区域标题: 16px Semibold (金色)
- 卡片标题: 14px Semibold
- 正文: 13px Regular, 行高 1.7
- 辅助: 11px
- 元数据: 10px
