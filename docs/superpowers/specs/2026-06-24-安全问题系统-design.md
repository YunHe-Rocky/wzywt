# 安全问题系统 — 设计文档

## 目标

用安全问题体系替换邮箱验证码系统，用于注册、修改密码、注销账号的身份验证。

## 功能范围

### 注册
- 用户名 + 安全问题（下拉选择）+ 安全答案 + 密码 + 确认密码
- 安全问题列表：8 个预设 + 1 个"自定义问题"选项
- 选择自定义问题后显示额外输入框
- 移除邮箱和验证码字段

### 登录（视觉升级）
- 同套金纹紫底视觉风格
- 忘记密码入口保留，改为安全问题验证流程

### 忘记密码（登录页）
- 输入用户名 → 查出该用户的安全问题 → 显示问题 → 填写答案
- 答案验证通过 → 输入新密码 + 确认密码 → 修改成功

### 修改密码（/me 个人空间新增）
- 新增"修改密码"按钮
- 点击后弹出安全问题验证 → 答对后显示新密码/确认密码 → 提交修改

### 注销账号（/me 危险区域）
- 原有：输入 DELETE + 输入密码
- 改为：输入 DELETE + 回答安全问题
- 两者都完成按钮才激活

## 数据库变更

User 表：
- 新增 `security_question` VARCHAR(255) — 安全问题文本
- 新增 `security_answer_hash` VARCHAR(255) — bcrypt 哈希
- 删除 `email` / `email_verified` / `reset_code` / `reset_code_attempts` / `reset_code_expires`

### 旧数据迁移
- `email` 字段直接删除（存量用户注册时未填邮箱的情况需要处理）
- 已有用户首次使用新功能时引导设置安全问题（在修改密码/注销时提示）

## API 变更

| 路由 | 变更 |
|------|------|
| `/api/auth/register` | 去 email/code，加 securityQuestion/securityAnswer |
| `/api/auth/send-code` | 删除 |
| `/api/auth/reset-password` | 改为：username → 查问题 → 校验答案 → 设新密码 |
| `/api/auth/me` DELETE | 密码校验 → 安全问题校验 |
| `/api/auth/change-password` | 新增：安全问题校验 → 设新密码（需登录态） |
| `/api/auth/me` GET | 返回用户是否有安全问题（hasSecurityQuestion） |

## 答案存储与校验

- 答案输入时 trim 去除首尾空格
- bcrypt hash 存储（cost=10，与密码一致）
- 验证时 trim 后 bcrypt.compare

## 视觉设计

所有认证相关 UI 统一升级：

- 背景：深紫渐变 `#1a1830 → #12101c`
- 边框：金色微光 `rgba(192,168,74,0.12)`
- 标题：渐变金字 `#d4b85a → #a08030`，letter-spacing 2px
- 按钮：金色渐变 + 发光阴影
- 标签：金色大写 `#b0a060`，letter-spacing 1px
- 注销相关用红色调替代金色
- 移动端：字号缩小、间距收窄、输入框加高，断点 480px
