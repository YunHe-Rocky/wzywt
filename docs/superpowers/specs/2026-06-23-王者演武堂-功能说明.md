# 王者演武堂 — 功能说明

> 面向选手与赛事组织者

---

## 一、这是什么

一个内战分队工具。你维护好自己的分路偏好和英雄战力，系统自动帮你分出实力均衡的红蓝两队。

---

## 二、怎么用

### 第一步：注册账号

用任意用户名和密码注册，后面随时可以改个人信息。

### 第二步：配置个人数据

进入「个人空间」：

1. **分路偏好排序**：五个分路（对抗路、打野、中路、发育路、游走），从最想玩到最不想玩排个序
2. **擅长英雄**：每个分路选 1-3 个擅长的英雄，填上战力

随时可以回来改。

### 第三步：创建或加入赛事

**如果你是房主**：
- 在赛事大厅点「创建赛事」
- 起个名（如"周六内战"），设一个截止时间
- 把赛事号发群里

**如果你是选手**：
- 输入房主发的赛事号，点「加入」

### 第四步：等待截止

截止时间到，系统自动锁定名单并分队。人数不够会问房主是延长时间还是强行分队。

### 第五步：看结果

分队结果展示红蓝两队，每个人的分路、战力一目了然。不满意结果房主可以重新分队。

---

## 三、权限说明

| 能做啥 | 房主 | 次房主 | 普通选手 |
|--------|:--:|:--:|:--:|
| 加入/退出赛事 | ✓ | ✓ | ✓ |
| 提交临时人员申请 | ✓ | ✓ | ✓ |
| 延长截止时间 | ✓ | ✓ | |
| 手动分队/重新分队 | ✓ | ✓ | |
| 踢人 | ✓ | ✓ | |
| 审批临时人员 | ✓ | ✓ | |
| 添加临时人员 | ✓ | ✓ | |
| 任命次房主 | ✓ | | |
| 取消赛事 | ✓ | | |

- 房主操作后 **5 分钟内**，次房主不能做相同操作
- 房主可以把其他人设为次房主，分担管理压力

---

## 四、临时人员

碰到群里有人没注册但想临时参战：

- 任意选手提申请（可以帮他填些资料，也可以不填）
- 房主或次房主审批
- 通过后临时人员以空壳加入
- 推荐人、房主、次房主后续都可以帮他补填分路和战力

---

## 五、分队规则

1. **实力优先**：两边巅峰战力尽可能接近
2. **分路偏好次之**：在不影响平衡的前提下，尽量让每个人玩到想玩的分路

---

## 六、阵容演练

分队结果出来后，每队可以在系统里提前规划各局上场的英雄——纯参考，实际怎么选英雄还是进游戏再说。

---

## 七、英雄数据

系统每天自动同步王者荣耀官方英雄数据，选英雄时能看到英雄名、技能介绍等信息。
