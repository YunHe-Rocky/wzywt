## 命格系统规格

### 图鉴卡片
- 命格形态英雄（如"心魔六耳"）：不在图鉴中展示
- 本命英雄（如"孙悟空"）：显示「⇄ 双形态」金色徽章
- 点击 → 直接进入详情页

### 详情页双标签
- 顶部显示 `[本命 · 英雄名] [命格 · 命格名]`
- 激活标签: 金色(蓝)边框 + 背景高亮
- 切换后更换: 名称、称号、图片、皮肤、技能

### 命格绑定
- `scripts/migrate-mingge.ts` 维护映射表
- 爬虫只检测，不覆盖手动绑定
