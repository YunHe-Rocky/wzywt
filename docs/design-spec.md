## 弹窗规格

### 通用弹窗结构
```
┌─────────────────┐
│  🌟 辉光 (modal-glow)│
│                 │
│  标题           │
│  内容           │
│                 │
│  [主按钮] [取消]  │
└─────────────────┘
遮罩: 半透明黑底, click-outside 关闭
```

| 属性 | #1 演武 | #2 厚玻璃 |
|------|---------|-----------|
| 卡片背景 | 暗色 `var(--bg-card)` | 78% 白底 + blur(20px) |
| 遮罩 | `rgba(0,0,0,0.5)` | `rgba(0,0,0,0.25)` + blur(4px) |
| 辉光色 | 金色 radial | 蓝色 radial |
| 边框 | `var(--border-gold)` | 白色半透 |
| 按钮 | 金色渐变, 6px | 蓝色渐变, 20px |

### 所有弹窗无障碍标准
- `role="dialog"` + `aria-modal="true"`
- 打开时自动聚焦第一个输入框
- Tab 键在弹窗内循环（焦点陷阱）
- Esc 键关闭弹窗
- 关闭后焦点复位

## 命格系统规格

### 图鉴卡片
- 命格形态英雄（如"心魔六耳"）：不在图鉴中展示
- 本命英雄（如"孙悟空"）：显示「⇄ 双形态」金色徽章
- 点击徽章 → 卡片内切换到命格形态显示

### 详情页双标签
- 顶部显示 `[本命 · 英雄名] [命格 · 命格名]`
- 切换后更换: 名称、称号、图片、皮肤、技能

### 命格绑定
- `Hero.mingge` + `minggeName` + `minggeRelatedId`
- 爬虫检测命格关键词（仅发现时更新，不覆盖已有）
- `minggeRelatedId` 支持双向关联（如孙悟空↔心魔六耳互相引用）
