# V1.0.0 — 王者演武堂正式上线

基于安全问题的认证体系上线，5v5 内战分队系统完整可用。本公告介绍系统功能与使用流程。

## 快速开始

### 第一步：注册账号

访问注册页，填写召唤师名称、选择安全问题、输入安全答案、设置密码（至少11位）。

> ⚠️ 安全问题用于找回密码和注销账号时的身份验证，请务必记住你的答案。

### 第二步：配置个人战力

登录后进入**个人空间**，配置你的游戏数据：

- **分路偏好与段位** — 选择你擅长的分路（上路/打野/中路/射手/辅助）和当前段位。段位影响分队平衡的核心权重。
- **英雄战力** — 搜索并添加你擅长的英雄，输入战力值。分队时系统会尽量让你拿到擅长的英雄所在分路。

> 💡 数据越准确，分队越公平。分队权重：段位覆盖(×100) > 段位均衡(×50) > 偏好满足(×10) > 战力均衡(×1)

### 第三步：创建或加入房间

**创建房间：** 在赛事大厅点击"创建赛事"，填写房间名称、截止时间，可选择设为公开让其他人自由加入。

**加入房间：** 赛事大厅可看到公开房间列表，点击直接加入。私有房间需要房主分享房间码。

## 房间管理

### 房主权限

| 操作 | 说明 |
|------|------|
| 分队 | 满 10 人后一键自动均衡分队 |
| 踢人 | 移除选手（被踢管理会先自动降级） |
| 延长截止 | 延长报名截止时间 |
| 公开/私有切换 | 控制房间是否在大厅展示 |
| 任命/撤销管理 | 指定其他选手为管理员 |
| 编辑公告 | 修改房间公告内容 |
| 补位选手 | 添加虚拟人员填补空缺 |

### 管理权限

| 操作 | 说明 |
|------|------|
| 分队 | 同房主 |
| 踢人 | 同房主 |
| 延长截止 | 房主操作后 5 分钟内不可重复 |
| 辞去管理 | 主动放弃管理权限，降为普通选手 |

## 分队算法

取前 10 人组成 5v5 对战，多余选手静默排除。分队权重优先级：

1. **段位覆盖**（×100）— 确保红蓝双方各分路段位分布均衡
2. **段位均衡**（×50）— 双方整体段位接近
3. **偏好满足**（×10）— 尽量让选手拿到首选分路
4. **战力均衡**（×1）— 英雄战力总和平衡

分队结果持久化存储，刷新页面不会丢失。

## 账号安全

- **注册** — 选择安全问题（8 个预设 + 自定义），答案 bcrypt 加密存储
- **修改密码** — 个人空间点击修改密码，需先验证安全问题
- **找回密码** — 登录页点击"忘记密码"，输入用户名 → 回答安全问题 → 设新密码
- **注销账号** — 个人空间危险区域，需输入 DELETE 确认 + 安全问题验证
