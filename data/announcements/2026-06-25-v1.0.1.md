# V1.0.1 — 双主题架构 + 爬虫升级 + 命格系统

**2026-06-25**

本次更新带来全新的双主题视觉架构、爬虫机制重构以及英雄命格系统。

## 双布局适配
桌面端演武主题（暗金琉璃）与移动端厚玻璃主题（浅底蓝调）独立适配，URL 末尾加 `#1` 或 `#2` 手动切换风格。

## 爬虫机制升级
每 3 分钟自动对比官方英雄数据，检测新英雄/皮肤/命格变化，5 重 UA 轮换 + 退避重试保证稳定性。

## 命格系统
S44 赛季「不拘命格」上线，英雄图鉴新增命格筛选按钮，支持一键过滤命格英雄。

## 个人空间重构
段位信息与分路配置合并为一张卡片，保存按钮嵌入卡片底部，布局更紧凑。

## 其他优化
- 三颗动态光晕背景
- Dock 导航栏常驻
- 移动端自动 UA 检测跳转 /m 路由
- 所有组件硬编码颜色值替换为 CSS 变量
