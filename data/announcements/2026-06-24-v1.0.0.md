# V1.0.0 — 王者演武堂全新出发

全新 UI 设计系统上线，深色主题 + 金色点缀，适配电脑与手机。

## 功能

**分队系统**
- 10 人 5v5 自动均衡分队，综合分路段位、偏好、英雄战力与巅峰赛分值
- 综合战力评分：英雄战力 + 巅峰分 + 当前段位 + 历史最高段位
- 偏好优先：算法优先满足分路偏好，强者守主路，弱者补位

**个人空间**
- 当前段位：账号级别统一设置，带段位徽章
- 分路配置：偏好排序 + 英雄战力 + 巅峰赛分 + 历史最高段位
- 每个分路可添加 1-3 个擅长英雄，点开展开编辑

**赛事系统**
- 创建赛事、邀请码加入、公开房间大厅
- 房主/管理权限分离
- 分队结果持久化存储

**英雄图鉴**
- 官方数据同步，英雄详情 + 皮肤切换
- 分路管理手动修正

## 账号安全

- 注册需选安全问题 + 答案（bcrypt 加密）
- 密码至少 11 位，支持眼睛切换明文
- 忘记密码：用户名 → 安全问题 → 重置
- 注销需验证安全问题
