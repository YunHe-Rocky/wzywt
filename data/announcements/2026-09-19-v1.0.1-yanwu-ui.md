# V1.0.1 — 全站演武馆 UI 更新

版本：`v1.0.1` · 内部编号：`WZYWT-REL-0002` · 小版本

本地版本登记时间：2026-09-19 21:13:44 +08:00。本文件为站内公告稿，尚未写入生产公告或上线发布。

## 这次改了什么

- **全站换新**：首页、图鉴、房间、对局、战术、动态、个人中心和后台统一为纸白、墨色、朱砂的新中式演武馆风格，电脑和手机都覆盖。
- **手机导航更清楚**：底部为首页、演武、图鉴、动态四项书签，个人入口放在顶部；后台使用独立折叠菜单，避免重复导航。
- **新开屏动画**：朱印落款、墨线展开，支持跳过和重播，照顾减少动态效果设置，并修复切页后页面仍被锁住的问题。
- **交互细节收尾**：修复窄屏按钮遮挡、密码框文字拥挤、表格固定层级和后台横向溢出；完善退出失败与设置读取失败的反馈。
- **历史主题融入**：文化与庄重预览保持统一阅读风格，同时保留来源、日期、史实/评述说明和未发布提示。
- **完整截图验收**：26 类正式页面与 3 类调试页面均提供电脑、手机截图，另附开屏及关键状态。

## 本次范围说明

本次完成的是 UI 改版与本地组件验收。历史主题正式发布、真实服务和数据库联调、原爬虫内存与 CI 专项不在本次完成范围；截图中的内容为隔离测试数据，不代表线上数据。
